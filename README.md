## 🚀 Featured Projects

### 🏦 MY BANK — Agent Banking System
A full-stack banking management application designed to manage banking operations and multiple user roles.

- 🏢 Role-based dashboards for Head Office, Division Head, Branch, and Agent
- 💳 Account management, deposits, withdrawals, and transaction history
- 🔐 Authentication and protected routes
- 📊 Banking dashboards and operational reports
- 🧰 **Tech:** React, TypeScript, Redux Toolkit, RTK Query, Tailwind CSS, Node.js, Express.js, MongoDB

### 🛍️ Puraton Bazar — Used Products Marketplace
A marketplace concept for buying and selling pre-owned products.

- 📱 Product listings for mobile phones, laptops, cameras, and computers
- 🔎 Product discovery and management
- 🔐 Authentication and protected features
- 💳 Payment integration practice
- 🧰 **Tech:** React, Node.js, Express.js, MongoDB, Tailwind CSS

### 🍽️ Bistro Boss — Restaurant Management
A restaurant application featuring menu browsing, cart management, user functionality, and payment integration.

- 🍔 Dynamic menu and cart functionality
- 👤 User authentication
- 💳 Stripe payment integration
- 🧰 **Tech:** React, Firebase, Node.js, Express.js, MongoDB, Stripe
